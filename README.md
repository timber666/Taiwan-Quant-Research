# Taiwan Quant Research Platform

台股量化研究與回測平台

## Project Goal

建立一套從金融資料 → 特徵 → 策略 → 模型 → 回測 → 績效分析的完整量化研究流程。
目標不是預測明天哪支股票會漲，而是打造一套可驗證、可重現的量化研究方法論。
